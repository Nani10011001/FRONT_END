 ⚙️ Setup & Run

 1️⃣ Clone the Repository
```bash
git clone https://github.com/your-username/frontend-learning.git
cd FRONT_END
```

 2️⃣ Install Dependencies
```bash
npm install
```

3️⃣ Start Development Server
```bash
npm run dev
```

 4️⃣ Open in Browser
```
http://localhost:5173
```
